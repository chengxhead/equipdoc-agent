# Legacy evidence

These JSON files are unmodified outputs from the original AutoDL experiment.

- Agent evaluation v4: 30 cases, with most tool routes triggered by deterministic `.npy` path/keyword rules.
- FP16 latency: nine serial requests across three prompts; the JSON does not record the GPU model.
- BNB 4-bit: one prompt and a memory snapshot; it is not a concurrent serving benchmark.
- Model storage report: records the size of the merged 7B model on the original AutoDL machine.

They are retained as historical evidence, not as final portfolio metrics.
