# P2 AutoDL Full 模式评测报告

## 1. 结论摘要

本次 P2 在 AutoDL 的单张 RTX 4090 上启动真实 `Qwen2.5-7B-Instruct-EquipDoc` 服务，并对20条固定知识问答执行一次预热后的串行端到端评测。对应 Git 提交为 `3226c70d57214865bfe99c160c646192caffeef6`。

系统20/20请求成功，14/20通过严格自动门槛，平均必需关键词召回率为91.25%。所有答案均在模型首轮完成证据句选择，没有触发重试或抽取式兜底；禁止性具体结论规避率、引用ID有效率、逐句引用覆盖率、引用原文逐字匹配率和参考文档命中率均为100%。串行端到端延迟 p50 为0.414秒，p95为0.433秒。

这些结果说明当前链路能够稳定返回可逐字回查的证据化答案，但不能解释为“答案正确率100%”或“groundedness 100%”。严格自动门槛暴露出的主要短板是多子问题场景下的证据选择不完整；AI辅助审查还发现少量自动通过答案存在上下文不匹配或无关证据。

## 2. 被评测系统

Full 模式知识问答链路如下：

1. BM25 对14篇公开知识笔记进行词法检索；
2. 根据问题中的明确设备或故障词执行聚焦检索；
3. 根据频谱分析、现场复核等问题意图重排候选证据句，并限制单一切片的前排占比；
4. Qwen 从候选集中选择4个证据句ID；
5. 系统按被选ID确定性渲染证据原句和 `doc_id#chunk_id` 引用；
6. 若选择格式不合格则重试一次，再失败才返回词法相关性最高的抽取式证据。

模型在本阶段承担证据选择，而不是自由撰写最终技术结论。这是从初始 Smoke Test 中发现无引用回答和错误技术扩写后采用的高保证设计。

## 5. 六条自动失败的审查

| 用例 | 自动缺失 | AI辅助审查 | 主要问题 |
|---|---|---|---|
| `full_003` | `BSF`、`调制` | 真实不完整 | 回答覆盖滚动体运动机理和现场复核，但漏掉题目要求的关键频谱线索 |
| `full_009` | `工况` | 接近字面误判 | 答案已列出负载、温度、噪声、历史趋势和生产风险，语义上覆盖了运行条件，但未出现“工况”原词 |
| `full_010` | `电流` | 真实不完整 | 覆盖测温基线和机械侧检查，但没有分别展开电气电流与冷却侧检查 |
| `full_016` | `补充数据` | 字面误判 | 原文使用“需要补充的数据”，语义满足要求，但未命中连续字符串“补充数据” |
| `full_017` | `采样位置` | 真实选择失败 | 混入两条管道泄漏证据，且未回答采样位置和运行工况为什么会改变振动特征 |
| `full_020` | `引用` | 部分覆盖 | 说明应附带来源 chunk，但没有充分解释可核验引用对证据审计和抑制编造的作用，并混入外圈故障证据 |

自动失败并不完全等于语义错误：`full_009` 和 `full_016` 主要是严格字面门槛造成的假阴性。另一方面，自动通过也不等于内容完全合适：例如 `full_007` 面向低置信度问题，却混入一条“置信度较高”的外圈处置证据；`full_013` 的核心对比正确，但附带两条泵类证据，相关性偏低。

## 6. 从初始失败到当前链路

初始3条真实模型 Smoke Test 的请求成功率为100%，但引用有效率和参考文档命中率均为0%，并出现 BPFO/BPFI/BSF 混淆和无证据频率关系。项目没有为提高数字而直接给错误文本补引用，而是依次增加：

- 完整 `doc_id#chunk_id` 引用格式；
- 逐句引用覆盖校验；
- 引用原文逐字匹配；
- 设备/故障聚焦检索；
- Qwen证据句ID选择；
- 确定性答案渲染与显式降级。

最终20条评测中没有出现未知引用、无引用技术句或超出引用原文的生成内容。代价是答案表达更偏抽取式，且选择器仍可能遗漏子问题。初始失败与最终 Smoke Test 均作为产物保留，而不是隐藏失败记录。

## 7. 结果边界

- 100%引用原文匹配只证明答案句能在当前知识切片中逐字回查，不证明知识笔记本身权威或完全正确；
- 当前知识库主要是项目自写笔记，后续仍需增加标准、教材、厂商手册等来源和版本元数据；
- 70%是20条固定用例上的严格自动通过率，不是开放域正确率；
- 人工复核CSV的三个0/1字段仍为空，因此不能声明人工 groundedness 或人工正确率；
- 延迟不包含并发吞吐和 TTFT，也不能与输出自然语言长答案的服务直接比较；
- 本次未启用向量库，结果属于 BM25 词法检索基线；
- 本阶段没有评测 CNN 准确率，旧 CNN 数据拆分问题仍然存在。

## 8. 下一步改进

1. 把多子问题先拆成“机理 / 信号 / 现场复核 / 边界”槽位，再要求每个槽位至少选择一条证据；
2. 将关键词门槛拆成字面召回和人工语义覆盖，减少假阴性；
3. 增加证据选择相关性标注，单独报告 selector Recall，而不是只看最终关键词；
4. 为知识文档增加权威来源、发布日期和适用设备范围；
5. 建立独立于开发集的留出测试集，避免继续针对当前20题调参；
6. 由具备机械诊断背景的复核者填写人工评审表后，再报告人工指标。
